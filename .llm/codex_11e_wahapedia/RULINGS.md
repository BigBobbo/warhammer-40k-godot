# Codex 11e rulings (one line each, per work package)

Rulings made while implementing ambiguous printed text. Format:
`- <rule>: <ruling> (<why>)`

## Data import (W / C1 / O1)
- Ork curated stratagems vs the 2026-10-16 export: identical text; Wahapedia's phase column for MOW 'EM DOWN and UNBRIDLED CARNAGE reads "Charge or Fight phase" while WHEN says "Fight phase, when ... selected to fight" — kept "Fight phase" (the WHEN governs use).
- Praesidium Shield: no stat bonus (codex: -1 D to attacks allocated to the bearer — WP-C7).
- Vexilla: +1 OC applies only to units whose roster took a Vexilla (wargear abilities are emitted only for wargear the roster lists).
- Units sold in fixed sizes are snapped to a printed size (Gretchin 11 -> 10); pre-codex Custodes model counts are clamped (Custodian Guard 4-5 -> Sodality 3).
- Legends datasheets (Lootas, Burna Boyz, Aleya, Valerian, ...) are not imported; roster entries for them are kept unchanged (owner decision D2).

## WP-C3
- Martial Ka'tah readied step: every friendly unit with the ability is readied at the start of its owner's Command phase, units in Strategic Reserves / embarked included (the text names no battlefield condition); the opponent's units never are. A unit stays readied until it uses a ka'tah (no end-of-turn clear), so a unit not used in its own turn can use Dacatarai / Kaptaris / Rendax in the opponent's Fight phase.
- Ka'tah UI: each ka'tah is a 0-CP "KA'TAH" card in the stratagem window of its WHEN (Conservai command_phase_main, Calistus unit_selected_to_move, Salvus unit_selected_to_shoot, Dacatarai/Kaptaris fight_phase_start, Rendax unit_selected_to_fight); the readied state is a gold "K" diamond on every model of the unit plus a "Readied" line in the hover card (the codex's "place a token next to each readied unit"). Using a ka'tah re-opens the window so a stratagem / another unit's ka'tah can still follow (none of these windows is "one choice only").
- Conservai's WHEN ("your Command phase"): offered in the new command_phase_main window, which opens when the player first starts the Battle-shock step (End Command / Roll Call / a test), just before battle_shock_step_start — after the readied step and the Command-step prompts. Its effect lasts until the end of the turn (cleared at the next Command phase start). "Eligible to start an action" covers the engaged and battle-shocked eligibility checks; an action already started still fails if the unit later becomes battle-shocked (core rule unchanged); "starting an action does not prevent shooting" also lets a unit shoot after starting one.
- Calistus: "move through all types of model" = friendly and enemy models, including MONSTER / VEHICLE bases, for normal, advance and fall-back moves only (not charge, pile-in, consolidation, or a Desperate Escape test — the fall-back itself still makes the tests the rules require); it does not let a model END on another model.
- Salvus "can ignore modifiers": the engine ignores exactly the harmful ones (BS worsening, negative hit-roll and wound-roll modifiers, including the cover hit penalty) and keeps the beneficial ones — the same choice the engine makes for [PSYCHIC]-style ignore text. Applied on both ranged resolvers; logged in the modifier ledger as "Salvus (Ka'tah)".
- Dacatarai / Kaptaris "Start of the Fight phase": offered only for readied units within 6" of an enemy unit (a unit farther away cannot make or receive a melee attack this phase — pile-in is 3"), at the start of either player's Fight phase, active player first. Dacatarai's re-roll of 1s is skipped (not wasted) against MONSTER / VEHICLE targets; Kaptaris is -1 to hit for every melee attack that targets the unit, both stacking with the core -1/+1 cap.
- Rendax [LETHAL HITS: MONSTER/VEHICLE] is keyword-qualified: critical hits auto-wound only when the target unit is a MONSTER or VEHICLE; weapons that already have [LETHAL HITS] are unchanged.
- Phase-scoped expiry: Calistus, Salvus, Dacatarai, Kaptaris and Rendax end with the phase they were used in (BasePhase.exit_phase); the effect flags and the readied flag are written on every component of an Attached unit, and the unit is a single target.
- Master of Ka'tahs ("Once per battle round, per unit: if this unit is not readied, you can use this ability; if you do, it is readied"): offered as a "Master of Ka'tahs" button on a ka'tah card for a NOT readied unit that contains the ability (an Attached unit led by a Shield-Captain counts), which readies the unit and uses that ka'tah at once. Being readied has no other effect, so readying earlier would only matter to SUPERHUMAN FOCUS ("not readied" target) — out of WP-C3 scope.
- Favoured Ka'tah: CustodesKatah.favoured_katah(player) returns "" and favoured_katah_extra_effect(...) returns [] until CustodesDetachments.gd (WP-C46) defines them; the card text gains "(Favoured Ka'tah)" when it is the favoured one.
- Aegis of the Emperor: FNP 5+ vs every mortal wound (devastating wounds, hazardous, Deadly Demise, stratagem / ability / explosives / crushing impact / emergency-disembark / Desperate Escape MWs). Against wounds that are both mortal and psychic the best FNP wins (Daughters 3+ beats Aegis 5+); FNPs never stack and never roll twice.
- Daughters of the Abyss: FNP 3+ vs Psychic Attacks only (mortal wounds from a non-psychic source do not get it — that is Aegis's job; the 10e "psychic and mortal" grant is gone). Psychic Null (Aura): friendly ADEPTUS CUSTODES units within 6" (edge to edge, any model) of a friendly ANATHEMA PSYKANA unit with Daughters of the Abyss that is on the battlefield get FNP 5+ vs Psychic Attacks; the ANATHEMA unit itself uses its own 3+.
- Aquila Commander: "start of the battle round" = the first-turn player's Command phase entry, after the per-round bonus-CP tracker resets; only if the player's WARLORD is alive and has the ability; once per battle round (a save/load re-entry does not pay twice); the CP is a bonus CP, refused (and logged) when the player already gained a bonus CP this battle round.
- Anathema Psykana: an ANATHEMA PSYKANA model cannot be designated WARLORD (Formations validation refuses DESIGNATE_WARLORD and the warlord picker / auto-pick skip them; the army builder warns in 11e) unless CustodesDetachments.anathema_psykana_warlord_allowed(detachment) says so (Null Maiden Vigil hook, stub false).
- AI: uses a ka'tah only when it clearly pays — Rendax when engaged with a MONSTER/VEHICLE, Dacatarai (own turn) / Kaptaris (opponent's turn) when engaged with non-MONSTER/VEHICLE enemies, Calistus for a fall-back, Salvus when no enemy is within 18" (long shots, most likely to carry a hit penalty); never Conservai (it does not plan actions). Master of Ka'tahs needs a higher score. Decisions are synchronous, so a window never waits on the AI.

## Integrator
- Bonus CP cap: the 11e core rules (08.02) have no per-round cap on gaining CP (10e had "1 extra CP per battle round"); Aquila Commander now matches Da Boss — no cap check, once per battle round. GameState.BONUS_CP_CAP_PER_ROUND is still applied engine-wide to other 10e-era CP sources — a core-rules follow-up, not changed here.

## WP-C5
- Window mapping: every WHEN is a stratagem window of the BasePhase framework (one handler per csv_id in CustodesCodexFight / Shooting / Movement / Other, dispatched by CustodesCodex11e.gd); new windows: unit_ended_advance_move, unit_selected_to_ingress, unit_selected_to_pile_in, unit_selected_to_consolidate, enemy_has_fought, charge_phase_start, charge_phase_end, phase_end. The "Your Shooting phase or the Fight phase" / "Your Command phase" / "Any phase, when ... has used" stratagems with no single trigger (HONOURED INTERRED, UNLEASH THE LIONS, GILDED CHAMPION) are S-panel stratagems with a friendly-unit picker; the panel acts for the human seat even during an AI turn.
- Duplicate rows (IN AURAMITE CLAD, SUPERHUMAN FOCUS, SWIFT AS THE EAGLE are printed in two detachments): one handler serves both csv_ids, each row has its own once-per-phase/turn ledger (only one detachment is ever loaded).
- phase_end ("End of any phase", SUPERHUMAN FOCUS): PhaseManager holds the phase transition after phase_completed while either player has a usable phase_end stratagem (active player first, then the opponent); not opened in networked games (the transition is host-driven) — single-player / hot-seat only; a nested open is refused.
- SUPERHUMAN FOCUS "not readied" uses the WP-C3 readied flag; "cannot select the same unit as the target more than once per battle round" is tracked per unit per battle round.
- INEXORABLE "ignore modifiers to Move, advance and charge rolls": the engine has no negative Move / advance-roll modifiers today (FLY take-to-the-skies is a distance cost, not an M modifier), so only harmful charge-roll modifiers (GRAVIMETRIC GRENADE's -1, other charge penalties) are dropped; beneficial ones are kept (the Salvus choice, WP-C3).
- Salvus-style "can ignore modifiers" (BEARERS OF HIS LIGHT hit + wound rolls, INEVITABLE ANNIHILATION BS + hit rolls): only harmful modifiers are ignored (BS worsening incl. cover, -1 to hit / to wound); +1s are kept; logged in the modifier ledger.
- NO ESCAPE: auto-resolved for either decider (no interactive charge UI in the opponent's Movement phase): 2D6 (+ the unit's own charge-roll modifiers), target = the enemy unit named by the window if it fell back this phase, else the closest unit that fell back within range; the move is the ReactiveMove11e "surge" solve (end engaged with the target, never with another enemy). Success grants what a charge grants (charged_this_turn, Fights First, the target has_been_charged); failure moves nothing. Flags cleared at the end of the turn.
- SELFLESS SERVICE: "declare a charge ... can only select the closest enemy unit within 6\"" — one target (the closest within 6"), 2D6 capped at 6 (it can never move further than 6"), moved through the Heroic Intervention machinery (charge path tools labelled SELFLESS SERVICE; AI uses _compute_charge_move); unlike a Heroic Intervention it is a charge, so it gains Fights First. Opened at the end of the opponent's Charge phase BEFORE the core Heroic Intervention prompt.
- RAPID REACTIONS: the shooting is auto-resolved (normal shooting at the unit that fell back, the GUN-CRAZY SHOW-OFFS executor's assignment rules); "engaged with that enemy unit at the start of the phase" uses the engagement snapshot MovementPhase takes on entry.
- SWIFT AS THE EAGLE: the D3+3" reactive normal move uses the Ork reactive_normal_move follow-up (the defender moves, then the phase returns to the active player); the AI never uses it (no objective-aware destination for a reactive move).
- GOLDEN LIGHT OF THE MOIRAIDES: unit_selected_to_ingress opens when the reserves unit is picked for placement (Main routes the pick; PLACE_REINFORCEMENT opens it itself for AI / direct actions and holds the placement until the answer); -1 to hit applies to ranged and melee attacks that target the unit; "cannot target with snap shooting attacks" removes it from Fire Overwatch and from the snap shooting type's targets; lasts until the start of the owner's next Command phase.
- FURY OF THE EMPEROR "made an ingress move this turn" = flags.arrived_from_reserves (set by every reserves arrival).
- GRAVIMETRIC GRENADE: target list = visible enemy units within 12" of the selected unit; the -1 applies to that enemy's charge rolls for the rest of the phase; INEXORABLE can ignore it.
- SHIELD OF HONOUR: offered only for INFANTRY / MOUNTED units with an enemy within 6" (as Dacatarai / Kaptaris, WP-C3); judged per attack batch — a batch from models engaged with the SoH unit that targets another unit gets -1 to hit and -1 to wound; a batch aimed at the SoH unit is penalised only if the same attacker also has confirmed attacks against another unit this activation.
- DUTY UNTO DEATH reuses the engine's Fight On Death (05.04.05) machinery: 3+ keeps the model (+1 for a CHARACTER model), and it cannot be used on a unit already selected to fight this phase (Ork ruling for the same text).
- INDOMITABLE GUARDIANS "eligible to fight" = engaged (or charged) and not yet fought; "must be the next unit selected" restricts the Custodes' fighter list to that unit until it fights; its granted Fights First is removed at the end of the phase.
- EMPEROR'S DOMAIN lifts only the mandatory order of the Before Moving consolidation modes; the objective mode's own condition (an objective within 3") still applies.
- LIGHTNING WRATH: D3 rolled on use; the pile-in cap becomes D3+3" for that move (the unit is not asked again in the same step).
- HONOURED INTERRED aura: friendly ADEPTUS CUSTODES units within 6" (edge to edge, the Dreadnought itself included) re-roll hit rolls of 1; no duration is printed, so it lasts until the end of the phase it was used in (the default for a stratagem effect).
- AVENGE THE FALLEN: +2 A for non-CHARACTER models only ("excluding CHARACTER models"); starting strength from the roster.
- PRIME TARGET: one hit, one wound and one damage re-roll per use; a human picks the die in the staged resolution dock ("PRIME TARGET (free)"), the auto resolver / AI re-rolls the first failed hit / wound and a damage roll below the dice average.
- PSY-CHAFF VOLLEY: "enemy unit hit by those attacks" = units with at least one successful hit in that shooting (window ctx hit_unit_ids); prosecuted = +1 AP for every attack that targets it until the end of the turn.
- VIGIL UNENDING / IN AURAMITE CLAD "until that enemy unit has attacked": ended by the shooter's post-shot hook / the fighter's activation end (on_unit_has_attacked); VIGIL's -1 D stacks on an existing -1 D and hands back only its own; IN AURAMITE CLAD worsens AP by 1 (AP 0 stays 0) and never targets CUSTODIAN WARDENS.
- ADVANCED STABILISERS: an advanced GRAV-ASSAULT unit stays selectable to shoot while the stratagem could be used; with it every ranged weapon counts as [ASSAULT].
- IMPENETRABLE BASTION / VICTORY BEFORE DEATH: "secured" = the objective stays under that player's control until the opponent controls it at the end of a phase (the engine's sticky-objective mechanic); BASTION lists the objectives the unit controls (OC >= 1, not battle-shocked) not already secured; VBD lists the objectives the destroyed unit was in range of with no enemy (non-AIRCRAFT) unit in range.
- UNLEASH THE LIONS: each new unit holds one model (starting strength 1, same datasheet / keywords / position, status deployed); the split cannot be undone.
- GILDED CHAMPION: works on any (Once per battle, per unit) datasheet ability the engine tracks — UnitAbilityManager's ledger or a unit flag (Moment Shackle: flags.moment_shackle_used) — the ability is restored from the next phase on ("not in this phase"), once per battle per model.
- AI: decisions are synchronous (decide_window_stratagem) so a window never waits on the AI; AI never uses UNSTOPPABLE MOMENTUM, INEXORABLE, SWIFT AS THE EAGLE, UNLEASH THE LIONS or GILDED CHAMPION (no reliable value model); LIGHTNING WRATH / EMPEROR'S DOMAIN reach the AI through its pile-in / consolidate step selection.

## WP-C46
- Starting strength (Moritoi Ancients, Creeping Dread, ...): a multi-model unit is below its starting strength while any of its models is destroyed; a single-model unit while it has lost one or more wounds. Below half-strength = GameState's check (fewer than half the models; a single model below half its wounds) (a lone Dreadnought would otherwise never be "below starting strength").
- "Friendly ADEPTUS CUSTODES unit" includes ANATHEMA PSYKANA units (they carry the ADEPTUS CUSTODES faction keyword in the codex data); an Attached unit counts when any component has the keyword (19.03).
- Martial Mastery: a free card with two options ([SUSTAINED HITS 1] / [LETHAL HITS]) in the unit_selected_to_fight window; declining the card picks nothing; the choice lasts until the end of the phase; a weapon that already has the chosen ability is unchanged.
- Magna Imperator: once per unit per phase for each roll type (one hit re-roll, one wound re-roll; an Attached unit is one unit); the engine re-rolls the first failed die that was not already re-rolled (re-rolling a failed die never hurts, so there is no prompt); the hit re-roll is not used for snap shooting (Fire Overwatch) or an [INDIRECT FIRE] shot at an unseen target (10.07 forbids hit re-rolls there); a die another re-roll (e.g. PRIME TARGET) already re-rolled is skipped; named "Magna Imperator" in the modifier ledger.
- Gilded Guardians / Wardens of the Dark Cells: the attack's Strength and the target's Toughness as the resolver uses them (after modifiers); "within range of an objective" = the objective-control predicate for any model of the target (Attached unit included); MONSTER / VEHICLE excluded when any component has the keyword.
- Assemblage of Might: one dreadful foe at a time, chosen in the command_phase_main window (it opens when the Battle-shock step starts, after the readied step); it lasts until the start of its owner's next Command phase; the +1 to wound applies to CHARACTER models' attacks — a ranged batch that mixes a CHARACTER with bodyguard models firing the same weapon does not get it (one profile per batch); an Attached enemy unit is one target.
- Heralds of the Throne: Fights First for every friendly ADEPTUS CUSTODES unit (FightSequencer.is_fights_first and FightPhase priority).
- Talon Sortie: the fall-back move keeps charge eligibility; shooting after falling back is still forbidden.
- On Gilded Wings: offered in the fight_phase_end window of the OPPONENT's Fight phase for each unengaged ADEPTUS CUSTODES TERMINATOR unit; the unit goes to strategic reserves as a 20.02 repositioned unit (status IN_RESERVES, reserve_type strategic_reserves, flags.repositioned_to_reserves), the whole Attached unit with it.
- Moritoi Ancients: +2 OC is added in objective control while the DREADNOUGHT is at starting strength; the re-roll-1s effects are logged as "Moritoi Ancients".
- Flare Shields: a 4+ invulnerable save vs ranged attacks for units with the GRAV-ASSAULT keyword (the better of it and any other invulnerable save is used; the save roll uses whichever of armour / invulnerable is better, as always).
- Silent Sisterhood / Creeping Dread: "makes a battle-shock roll, with -1" = one battle-shock test at -1 in the Battle-shock step of the opponent's Command phase (a unit already testing for being below half-strength takes one test, also at -1 — never two); PSYKER or below starting strength; 12" from any model of the ANATHEMA PSYKANA unit; battle-shock-immune units are skipped. The roll card shows "-1 Creeping Dread". PROSECUTOR SQUAD BATTLELINE is written into meta.keywords at army load and refreshed at the owner's Command phase. An ANATHEMA PSYKANA CHARACTER may be the WARLORD (WP-C3 hook).
- Favoured Ka'tah riders follow the codex lines through the WP-C3 CustodesKatah hooks; Dread Host Dacatarai's "-2\" from that pile-in/consolidation move" lowers the enemy unit's 3" maximum (never below 0) while it is engaged with the Dacatarai unit.
- Start-of-phase enhancement abilities (Pareldor's Caducatrix, Inspirational Exemplar, Sally Forth) share one free window, cus11e_phase_start, opened by BasePhase at phase entry for the active player first, then the opponent, only when a choice exists.
- Eagle's Eye "when attacks are allocated to this model": offered in the enemy_targets_unit_shooting / enemy_targets_unit_fight window (the last decision point before allocation); the 3+ InSv lasts until the end of the phase; once per battle per army.
- Superior Creation: rolled at the end of the phase in which the bearer was destroyed (once per battle per army); on a 2+ it is set up as close as possible to its death position, unengaged (rings of 0.5" up to 18"), with 3 wounds remaining.
- Unstoppable Destroyer "any consolidation mode, regardless of the Before Moving restrictions": the mandatory 12.08 order is lifted, but each mode's own condition still applies (engaged / an enemy within 3" / an objective within 3"), as EMPEROR'S DOMAIN spells out for its objective mode; the consolidation dialog offers a mode picker. Pile-in and consolidation maximum 4".
- Huntress' Eye: once per Movement phase per bearer, offered at the end of the Movement phase (movement_phase_end window); one visible enemy unit within 12" tests at -1.
- Leonine Ferocity / Celeritous Sentries: the core stratagem costs 1 CP less on the bearer's unit and that use does not count towards the stratagem's once-per-phase limit (Leonine once per phase per army; Celeritous once per phase per unit, only on a TRUSTED SENTINEL unit).
- Castellan's Mark: "up to three friendly ADEPTUS CUSTODES units" includes the bearer's own unit (Razgit's Magik Map excludes its bearer by its own text); it shares the redeploy-enhancement plumbing.
- Emperor's Light / Auriferous Orb: weapon profiles from the Wahapedia faction page (the CSV export drops the enhancement weapon table); granted weapons carry granted_by so the roster wargear filter keeps them.
- Bearer-only enhancements (Bane of Abominations, Edge of the Blade, ...): a ranged batch that mixes the bearer with other models firing the same weapon does not get the bearer-only effect (one profile per batch).
- Army-construction checks (EnhancementRules11e, data-driven, all factions): detachment membership, the printed bearer restriction, normal enhancements on CHARACTERs only, no enhancement (Upgrades included) on an EPIC HERO, one enhancement per unit ("each to a different unit"), once per army (Upgrades: up to three units, "(one per army)" one), the 2-per-1000-points cap (an Upgrade counts once). They are reported as army-load warnings, not errors (rosters from older builders spell names differently or predate the codex; a hard error would stop those armies loading). An army whose faction module owns its enhancement validation (WP-O5 OrkEnhancements11e.owns_army_validation) skips these generic checks, so no duplicate warnings.
- Upgrades: the core rules (Select Enhancements) say Upgrades "can be given to non-CHARACTER units" — an addition, not a limit. An Upgrade is never refused for being on a CHARACTER: any non-EPIC HERO unit its printed restriction allows may take it (Auric Eagle on a foot Shield-Captain; the Ork codex "Big Mek with Shokk Attack Gun model only" Upgrades Temperamental Shokka / Enhanced Runt-maw on their CHARACTER). Same rule in the army builder (enhancement-rules.mjs canBear) and the game (EnhancementRules11e.bearer_problem).

## WP-C7
- Activated datasheet abilities are 0-CP "Ability" cards in the stratagem-window framework (`cus11e_ab_<slug>` ids, routed by StratagemManager to CustodesAbilities.use; a secondary picker for "select one enemy unit"; two variant buttons for Moment Shackle): Vengeful Surge / Repulsor Suspensor Technology (enemy_has_shot), Sanctified Flames / Mobile Hunter (unit_has_shot), Purity of Execution (unit_selected_to_shoot), Archeotech Teleport-shunter (movement_phase_start), Take Wing / Infernus Firebombs (fight_phase_end of the opponent's Fight phase), Moment Shackle / Neutronium Cascade Mine / Sword of the Throne (phase_start). After a use the same window is offered again while another offer is left (decline closes it); every ability is limited to one use per trigger, so neither a human nor the AI can loop on a re-offer.
- "At the start of any phase": a new phase_start event window, queued by BasePhase.enter_phase BEFORE the phase's own start rules (so it resolves before e.g. fight_phase_start / ka'tah cards), for the active player first, then the opponent, only for a player who has an offer, in the Command, Movement, Shooting, Charge and Fight phases. Not opened in networked games (a window raised outside an action result cannot be mirrored — the WP-C5 phase_end ruling). Re-entering a phase (a save loaded at a phase start) offers it again. WP-C46's enhancement window (cus11e_phase_start) opens right after it.
- Moment Shackle "once per battle, per army": spent = any friendly unit carries `moment_shackle_used` (the flag GILDED CHAMPION clears to restore it). The prompt is offered only where an effect can change an attack — every Fight phase (+3 A / 3+ InSv), the opponent's Shooting phase and your own Charge phase (3+ InSv vs Fire Overwatch); in other phases no prompt. "This model" 3+ InSv applies to Trajann's own model, also inside an Attached unit (allocation copy). AI: +3 A in its own Fight phase / 3+ InSv in the opponent's, only with an enemy within 6".
- Praesidium Shield (Shield-Captain): -1 D (minimum 1) per attack allocated to the bearer's model — applied per allocated attack in the 11e allocation damage provider (interactive, auto-resolve, overwatch, melee), after other damage changes, and logged as a dice-log line "Praesidium Shield: -1 Damage (a -> b) — attack allocated to <name>". In an Attached unit only attacks allocated to the Shield-Captain's model are reduced. Sentinel Guard Sodality's Praesidium Shield is the -1-to-wound-if-S>T rule (shared hook with Unyielding Ancient). Damage reductions do not stack, as everywhere in the engine (EffectPrimitives takes the largest): when the unit already has a -1 D (e.g. a stratagem) the shield adds nothing; minimum 1 either way.
- Vexilla "can ignore modifiers to this unit's Ld": "can" = the player's choice, so the engine ignores the harmful Leadership-characteristic modifiers (e.g. Mek Gunz MADCAP ARTILLERY "zapped" -1 Ld) and keeps the beneficial ones; modifiers to the battle-shock ROLL (Sanctified Flames vs PSYKER, Creeping Dread) are not Ld modifiers and still apply.
- Vengeful Surge / Repulsor Suspensor Technology "lost a wound as a result of those attacks": the unit (any model; Attached unit for Vengeful Surge) is in the shot's wounded set; a unit that is engaged (Repulsor: printed; Vengeful Surge: 21.02 surge moves need an unengaged unit) or battle-shocked (surge move) is not offered. The surge move uses the engine's surge template (toward the closest enemy, ending engaged if possible) with D6+2"; the D6" normal move uses the reactive normal-move template (drag / Auto-move / Confirm panel).
- Archeotech Teleport-shunter "in your Movement phase, not selected to move": offered at the start of your Movement phase (movement_phase_start), battle round 2+ only (strategic reserves cannot arrive in round 1, 20.03); the whole Attached unit goes to strategic reserves and END_MOVEMENT is refused until it has made its ingress move.
- Sweeping Advance "if this unit was eligible to fight this phase": it fought, or it is engaged now, or it was engaged / had charged when the Fight phase started (stamped at Fight phase entry). The move is a normal / fall-back move of up to M: the drag mode it borrows from pile-in no longer applies the 3" cap or the "move closer to the enemy" rule.
- Sword of the Throne "at the start of the first battle round": offered at the start of the first phase of battle round 1 (the Command phase) through the phase_start window; "each time the mark is destroyed" → offered again at the start of the next phase. The +1 to wound applies to the Blade Champion's own attacks only ("this model's attacks"), against the mark or any unit it is attached to (Attached-unit head).
- Slayer of Tyrants / Unyielding Ancient / Praesidium Shield (Sentinel Guard): T and S are the values the resolver uses; an Attached unit's T is the bodyguard's (19.02).
- Impenetrable Defence / Stand Vigil "within range of an objective": the objective-control range predicate for any model of the unit (Attached unit included) or of the target.
- Infernus Firebombs: "until the end of your next turn" = through the Custodes player's next turn (the flag is armed when that turn starts and cleared when it ends); one use per Ares per phase end.
- Sanctified Flames: one use per shot ("when this unit has shot"); the battle-shock roll is 2D6 (-1 vs PSYKER) against the unit's best Ld; a fail battle-shocks the whole Attached unit.
- Purity of Execution "detected (+3\" detection range)": until the end of that Shooting phase (the printed text gives no duration; the ability is used "in your Shooting phase"); the effect names no observer, so TerrainManager adds 3" to that unit's detection range for every observer; once per phase per Prosecutor unit, offered when the Prosecutors are selected to shoot.
- Swift Ruin: Rapid Ingress on the Venatari with Verutum Lances costs 1 CP less and neither counts against nor is blocked by the once-per-phase limit (once per phase, per army). It shares StratagemManager's ignore-once-per path with WP-C46 Leonine Ferocity; both discounts can stack to 0 CP (never below). (The 11e RAPID INGRESS row is used at the start of the opponent's Shooting phase; no window offers it (the 10e end-of-Movement dialog never fires at edition 11, and nothing handles its start_of_phase trigger); a human can reach it only from the S panel when the active player is the AI. Swift Ruin is therefore validated headless only. Not a WP-C7 change; flagged.)
- Mobile Hunter "not eligible to declare a charge until the end of the turn": a hard lock in ChargePhase, RulesEngine.eligible_to_charge and the 11e charge template (like GRAB IT); it expires at the end of the turn.
- Not implemented (documented, not faked): Assault Vehicle (the core rules define no "shock disembark move"); Advanced Firepower (re-roll ONE hit / wound / damage roll vs MONSTER/VEHICLE — needs single-die re-roll plumbing; WP-C46's Magna Imperator helpers could host the hit/wound part). Their ABILITY_EFFECTS rows say `implemented: false`.

## WP-O34
- Waaagh!
