AR measuring test

Checks whether this tablet can measure the table in augmented reality, and how accurately — before anything bigger is built into Combat Calc. Works offline once this page has been opened once. Nothing is sent anywhere: copy or download the results and share them.

How to test

  1. Lay a tape measure flat on the table (or use the table edge: 44" / 60").
  2. Tap Start AR, point the camera at the table and move it slowly until the ring sits on the table.
  3. Accuracy: type the true distance, tap the ring onto the tape's 0, then onto that mark, then Record. Do 12", 24" and 44" a few times each, from different places around the table.
  4. Drift: tap Drift test, mark a spot (e.g. an objective's centre), walk round the table for ~30 s, come back and mark the same spot again.
  5. End AR, then Copy results and paste them to Claude.
